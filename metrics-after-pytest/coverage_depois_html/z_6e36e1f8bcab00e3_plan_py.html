1"""The one place that decides how a session is launched, and says so out loud. 

2 

3⛔ THIS MODULE EXISTS BECAUSE THE SAME FACT WAS COMPUTED IN TWO PLACES. The tool 

4that starts a session decided from its ARGUMENTS, and the browser launched from 

5`launch_kwargs(os.environ)`. Nothing kept them in agreement, so they drifted in 

6the way two copies always drift, and the answer handed back to the caller 

7described a browser that had not been started: 

8 

9 * with a profile set in the environment, `identity.resolve_seed` never saw it, 

10 so the seed was drawn fresh on every session while the cookie jar persisted. 

11 Three sessions on one profile, three different fingerprints, one login. That 

12 is the exact tell `identity.py` was written to prevent, reintroduced by the 

13 code that called it. 

14 * the answer said `profile: none, so nothing survives this session` while a 

15 persistent profile was open. 

16 * `identity.py` was only ever reached from one optional tool, so the whole 

17 identity decision was skipped on the path the tool descriptions actively 

18 recommend ("you do not have to call it at all"). 

19 

20So there is now one function. It takes what the caller said and what the 

21environment says, decides everything once, and returns both the kwargs the 

22browser is launched with AND the sentence describing them. The sentence cannot 

23disagree with the launch because it is derived from the same object. 

24 

25`config.launch_kwargs` was the second reader and is gone: it went on parsing 

26STEALTHFOX_PROXY after the exit had been decided here, so a malformed value 

27nobody was going to use still killed the session. Every STEALTHFOX_* variable 

28now has exactly one reader, and it is in this file. 

29"""

40#: Passed for `profile` or `proxy` to mean "explicitly none", as opposed to 

41#: `None` which means "I did not say". Without the distinction a caller cannot 

42#: turn OFF something the environment set, and the one scenario that needs it - 

43#: checks that must not be linkable to each other - is unreachable. 

44NONE = "" 

45 

46#: Words a caller passes when it meant NONE and echoed the answer back instead. 

47#: Each is a legal directory name, so without this they are created rather than 

48#: refused. Kept deliberately short: this catches an echo, not a typo, and a 

49#: longer list would start refusing directories people meant. 

50_NOT_A_PATH = frozenset({"none", "null", "nil", "no", "false", "undefined"})

53def describe(kwargs: Mapping[str, Any], seed_from: str = "", 

54 exit_note: str = "", warnings=()) -> str: 

55 """The sentence a caller is told about a session, read from the KWARGS the 

56 browser was launched with. 

57 

58 ⛔ It reads the launch, never the arguments that produced it. The answer 

59 used to be assembled from what the tool was CALLED with, so a profile 

60 arriving from the environment produced "profile: none, so nothing survives 

61 this session" over a browser holding a persistent profile - the caller was 

62 told the opposite of what happened, in the same breath as being told the 

63 seed. Anything derived from the launch cannot drift from it. 

64 

65 `browser_open` knows two things this cannot: where the seed came from, and 

66 why there is no proxy. They are passed in rather than recomputed, and 

67 `browser_status` simply omits them. 

68 """ 

69 profile = kwargs.get("profile_dir") 

70 proxy = kwargs.get("proxy") or {} 

71 seed = kwargs.get("seed") 

72 parts = [ 

73 "identity: seed %s%s." % (seed, " (%s)" % seed_from if seed_from else ""), 

74 "exit: %s." % (proxy.get("server") or exit_note 

75 or "this machine's own address, with no proxy in the way"), 

76 "profile: %s." % (profile or "none, so nothing survives this session"), 

77 "headless: %s." % ("yes" if kwargs.get("headless") else "no"), 

78 ] 

79 return " ".join(parts) + "".join("\nwarning: " + w for w in warnings)

82@dataclass(frozen=True) 

83class SessionPlan: 

84 """Everything decided about one session, and where each part came from.""" 

85 

86 kwargs: dict 

87 seed: int 

88 seed_from: str 

89 exit: str 

90 profile: Optional[str] 

91 warnings: tuple = field(default=())

93 # ⛔ `describe(self)` STOOD HERE AND WAS A SECOND MAPPING OF THIS OBJECT 

94 # ONTO THE SENTENCE. It forwarded all four fields to the function above, and 

95 # so did `work.open`, which is the only place the product ever says this out 

96 # loud - two copies of "which field is which parameter", free to disagree the 

97 # day a fifth field joins the sentence. 

98 # 

99 # It also described something that does not happen. A plan does not reach 

100 # the caller unchanged: between planning and launching, `work.open` can 

101 # rewrite the settings and the exit note, which is how the helper browser 

102 # comes to share `main`'s exit. The sentence a caller is told is read from 

103 # what was LAUNCHED, never from what was planned - the whole point of the 

104 # module function - and a method on the plan quietly offered the other 

105 # thing. Its six callers were all in one test file, and they now go through 

106 # the function the product goes through.

109def _asked(explicit: Optional[str], env: Mapping[str, str], name: str) -> str: 

110 """The value this session was asked for: the caller's, or the environment's. 

111 

112 ⛔ THE THREE-VALUED RULE, WRITTEN ONCE. `None` means the caller said 

113 nothing, so the environment decides; anything else is the caller's word, 

114 including `NONE` - the empty string - which is an explicit refusal and 

115 beats the environment. Without that distinction a caller cannot turn OFF 

116 what the environment turned on, and the one scenario that needs it, checks 

117 that must not be linkable to each other, is unreachable. 

118 

119 It was spelled out in both resolvers below, in two different shapes, with 

120 the second one's docstring saying "same three-way rule as the profile" - 

121 a claim a reader had to go and verify, and a claim that stops being true 

122 the moment one of the two is edited. 

123 """ 

124 return env.get(name, "") if explicit is None else explicit

127def _resolve_profile(explicit: Optional[str], env: Mapping[str, str]) -> Optional[str]: 

128 """Which profile directory this session uses, as an absolute path. 

129 

130 Three-valued through `_asked`: nothing said, an explicit refusal, or a 

131 value. 

132 

133 ⛔ The path is made ABSOLUTE here. A relative path resolves against the 

134 SERVER PROCESS's working directory, which the caller cannot see and does not 

135 control: the same string is a different directory when the client is started 

136 from somewhere else, and the login that was there yesterday is silently 

137 gone. Resolving it here at least makes the answer able to say which 

138 directory was actually used. 

139 """ 

140 chosen = _asked(explicit, env, "STEALTHFOX_PROFILE_DIR") 

141 if not chosen: 

142 return None 

143 if chosen.strip().lower() in _NOT_A_PATH: 

144 # ⛔ The answer says `profile: none, so nothing survives this session`, 

145 # and a caller reading its own transcript back passes that word as the 

146 # value. It is a legal directory name, so it would be CREATED: a brand 

147 # new empty profile, a sign-in wall, and nobody told that the profile 

148 # they meant was never opened. Refusing costs a message; accepting costs 

149 # a login. 

150 raise ValueError( 

151 "%r reads as a word rather than a directory. Pass \"\" to run with " 

152 "no profile at all, or a real path such as C:/tmp/acct-a. If you " 

153 "truly mean a directory of that name, give it as an absolute path." 

154 % chosen) 

155 return str(Path(chosen).expanduser().resolve())

158def _resolve_proxy(explicit: Optional[str], env: Mapping[str, str]) -> Optional[dict]: 

159 """Where the traffic goes out. 

160 

161 The same `_asked` rule as the profile, plus `STEALTHFOX_NO_PROXY`, which 

162 until now was read by nobody at all while sitting in client configuration 

163 files that looked like it worked. 

164 

165 ⛔ The veto applies to the ENVIRONMENT's answer only. A caller that passed 

166 a proxy asked for that proxy, and a variable set for a different session is 

167 not a reason to refuse it; a caller that passed `NONE` is refused already, 

168 by `_asked` returning the empty string. So the veto is read only when the 

169 caller said nothing, which is what the branch below says out loud instead 

170 of leaving it to the order of two returns. 

171 """ 

172 if explicit is None and env.get("STEALTHFOX_NO_PROXY", "") not in ( 

173 "", "0", "false", "False"): 

174 return None 

175 return proxy_from_url(_asked(explicit, env, "STEALTHFOX_PROXY"))

178def _describe_exit(proxy: Optional[dict], explicit: Optional[str], 

179 env: Mapping[str, str]) -> str: 

180 """⛔ Names the VALUE, not the variable it came from. 

181 

182 The answer used to say `exit: STEALTHFOX_PROXY`, which is a label. Somebody 

183 asked to reproduce yesterday's session cannot act on the name of an 

184 environment variable whose value has since changed, and the transcript that 

185 was supposed to make the session repeatable recorded nothing usable. 

186 

187 Credentials are deliberately absent: `proxy_from_url` splits them into 

188 separate keys, so `server` is already scheme://host:port and safe to print. 

189 """ 

190 if proxy is None: 

191 if explicit == NONE: 

192 return "this machine's own address, because you asked for no proxy" 

193 if env.get("STEALTHFOX_NO_PROXY", "") not in ("", "0", "false", "False"): 

194 return "this machine's own address, because STEALTHFOX_NO_PROXY is set" 

195 return "this machine's own address, with no proxy in the way" 

196 return proxy["server"]

199def engine_here(env: Optional[Mapping[str, str]] = None) -> dict: 

200 """The engine THIS process was told to launch, if it was told one. 

201 

202 ⛔ THE ENGINE IS A PROPERTY OF THE PROCESS, NOT OF THE SESSION, and keeping 

203 those two apart is the whole reason this exists. `WHO_A_BROWSER_IS` leaves 

204 `binary_path` out of what a session writes down, and rightly: it is a path 

205 on THIS machine, and a session carried to another one must resolve an engine 

206 rather than insist on a path that means nothing there. But leaving it out of 

207 the FILE was read as leaving it out of the browser, so a browser restored 

208 from a saved session came back without the engine the person had asked for. 

209 

210 Measured 2026-09-09, and it is not only a developer's problem. Somebody 

211 running `invisible-playwright-mcp ui --binary <their build>` and reopening a session got 

212 browsers on a DIFFERENT engine than the one they named, silently; on a build 

213 whose seal has no published assets - anything built locally - they got no 

214 browser at all, because there was nothing to download and nothing to run. 

215 

216 The transcript is what happened; the engine is what this build was asked 

217 for. Same shape as the system prompt, which a saved conversation used to 

218 carry back in place of the current one. 

219 """ 

220 env = os.environ if env is None else env 

221 named = env.get("STEALTHFOX_BINARY") 

222 return {"binary_path": named} if named else {}

225def launched_here(env: Optional[Mapping[str, str]] = None) -> dict: 

226 """What THIS process decides about every browser it starts, whoever the 

227 browser is: the engine it runs on, and whether its window is shown. 

228 

229 ⛔ TWO THINGS A SAVED SESSION MUST NOT DECIDE, read in one place. The engine 

230 was already kept out of the file (`engine_here`, and the reason above). 

231 `headless` was not, until 2026-09-14: the interface restored a `main` that 

232 a headed process had saved and showed its window on screen, uncloaked, at a 

233 launch that had asked for nothing of the kind - while the helper beside it, 

234 planned from this environment, stayed hidden. A launch flag written into an 

235 identity file outlives the launch it described. So the restore now writes 

236 this over whatever the file says, and the planner reads the same function, 

237 which is what keeps the two from disagreeing. 

238 """ 

239 env = os.environ if env is None else env 

240 decided: dict[str, Any] = { 

241 "headless": env.get("STEALTHFOX_HEADLESS", "1") != "0", 

242 } 

243 decided.update(engine_here(env)) 

244 return decided

247def plan_session(seed: Optional[int] = None, proxy: Optional[str] = None, 

248 profile: Optional[str] = None, 

249 env: Optional[Mapping[str, str]] = None, 

250 helper: bool = False) -> SessionPlan: 

251 """Decide everything about one session, once. 

252 

253 Every argument is three-valued: `None` means the caller said nothing and the 

254 environment decides, `NONE` means an explicit refusal that beats the 

255 environment, and a value is a value. 

256 

257 Raises `identity.IdentityConflict` when an explicit seed contradicts the one 

258 a profile already carries, and `ValueError` for an unusable proxy URL or an 

259 unreadable `STEALTHFOX_SEED`. Both are refusals rather than choices: going 

260 on would hand the caller a different person than the one they asked for. 

261 """ 

262 env = os.environ if env is None else env 

263 if helper: 

264 # ⛔ THE ENVIRONMENT'S PROFILE AND SEED DESCRIBE `main`, NOT THE HELPER. 

265 # A deployment sets STEALTHFOX_PROFILE_DIR so the identity keeps its 

266 # logins; read for `support` as well, it handed the helper main's own 

267 # profile directory. Firefox locks a profile to one process, so with 

268 # `main` open the helper could not start at all, and the engine said so 

269 # as "the pipe is closed" over a sandbox line nobody could act on 

270 # (measured 2026-10-01). The seed is the same mistake: the helper is a 

271 # different person, so an environment seed would make it main's twin. 

272 # The exit is still the environment's, as it is main's. 

273 env = {k: v for k, v in env.items() 

274 if k not in ("STEALTHFOX_PROFILE_DIR", "STEALTHFOX_SEED")} 

275 

276 directory = _resolve_profile(profile, env) 

277 chosen_proxy = _resolve_proxy(proxy, env) 

278 

279 # ⛔ The RESOLVED profile, not the argument. Passing the argument is what let 

280 # an environment profile keep its cookies while drawing a new fingerprint 

281 # every session. 

282 chosen_seed, seed_from = identity.resolve_seed(seed, directory, env) 

283 

284 warnings = [] 

285 if directory is not None: 

286 warnings.extend(identity.check_exit(directory, chosen_proxy)) 

287 

288 # ⛔ BUILT HERE, NOT BY A SECOND READER OF THE SAME VARIABLES. This used to 

289 # call `launch_kwargs(env)` and then pop the three fields it had just 

290 # decided, which left that function still PARSING STEALTHFOX_PROXY after the 

291 # exit was settled. Measured: with `STEALTHFOX_NO_PROXY=1` and a malformed 

292 # `STEALTHFOX_PROXY`, the session died on a value nobody was going to use - 

293 # and it died the same way when the CALLER had passed a perfectly good 

294 # proxy. Popping a duplicate is not removing it; every STEALTHFOX_* variable 

295 # now has exactly one reader. 

296 kwargs: dict[str, Any] = {"seed": chosen_seed} 

297 kwargs.update(launched_here(env)) 

298 if chosen_proxy is not None: 

299 kwargs["proxy"] = chosen_proxy 

300 if directory is not None: 

301 kwargs["profile_dir"] = directory 

302 

303 return SessionPlan( 

304 kwargs=kwargs, 

305 seed=chosen_seed, 

306 seed_from=seed_from, 

307 exit=_describe_exit(chosen_proxy, proxy, env), 

308 profile=directory, 

309 warnings=tuple(warnings), 

310 )
